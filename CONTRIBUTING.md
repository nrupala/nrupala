# Contributing

## Change management (PR-flow discipline)

This is Nrupal Akolkar's GitHub profile README repo (the special `nrupala/nrupala`
repository). It follows the standing PR-flow discipline — direct pushes to `main`
are retired:

- All changes land via **draft PRs** → he reviews and merges.
- **No direct pushes to `main`** — ever.
- Each PR adds a `CHANGELOG.md` entry under `## [Unreleased]`.
- This repo carries no version file, so no semver bump applies.
- Merge commits **reference the PR number**.
